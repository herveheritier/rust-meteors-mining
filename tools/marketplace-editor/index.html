✦ Place de marché — éditeur ✦

Application de gestion du jeu Meteors Mining : elle sert à la mise au point des objets vendus sur la place de marché accessible depuis la base — l'atelier d'amélioration du vaisseau et l'économie de la station (bouton UPGRADES de la boîte DOCK STATION, scénario Progression). Chaque modification est enregistrée automatiquement : en mode serveur, src/marketplace.rs se charge à l'ouverture et « 💾 Enregistrer le fichier » l'écrit directement dans le projet (src/scenario.rs n'a plus besoin d'être modifié).

Dans le jeu : les données ci-dessus sont les lignes d'atelier FUEL_UPGRADE_TRACK, AMMO_UPGRADE_TRACK, CARGO_UPGRADE_TRACK (avec leurs extensions), l'économie de la station (ELEMENT_VALUES, MODE_COSTS, FUEL_PRICE/FUEL_STEP, AMMO_PRICE/AMMO_STEP), les rangs de réputation (PROGRESSION_RANKS : seuils, noms et remises — lus par src/scenario.rs), le vaisseau joueur (VAISSEAU_JSON, VAISSEAU_SCALE, VAISSEAU_ORIENTATION_DEGREES, VAISSEAU_CENTER_X/Y_PERCENT — lus par src/vaisseau.rs) et le cosmonaute EVA (COSMONAUTE_JSON, COSMONAUTE_EVA_SCALE, COSMONAUTE_ORIENTATION_DEGREES, COSMONAUTE_CENTER_X/Y_PERCENT — lus par src/cosmonaut.rs) de src/marketplace.rs — un fichier généré par cet outil, importé par src/scenario.rs. Les extensions sont achetées au bouton UPGRADES de la boîte DOCK STATION (atelier « SHIP WORKSHOP », scénario Progression), persistées avec la progression (prog_up_fuel, prog_up_ammo, prog_up_cargo). Avec Chrome/Edge, « Ouvrir marketplace.rs » lie le fichier (lecture + écriture directe) : « 💾 Enregistrer le fichier » l'écrit ensuite sans copier/coller ; sans cette API, l'import et le téléchargement restent disponibles.

Serveur local (recommandé avec le navigateur intégré de VSCode) : lancez node tools/marketplace-editor/server.mjs puis ouvrez http://localhost:8123 — src/marketplace.rs est chargé automatiquement à l'ouverture, et « 💾 Enregistrer le fichier » l'écrit directement dans le projet, dans tous les navigateurs (sans sélecteur de fichiers ni API particulière).

Constante liée (non éditée ici) : CARGO_SIZE = 5 dans src/config.rs (capacité de base de la soute, référencée par CARGO_UPGRADE_TRACK).
